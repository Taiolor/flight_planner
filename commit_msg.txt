💡 What: Consolidated two separate `useMemo` hooks calculating annual metrics and totals from the `weeksData` array into a single `useMemo` block in `Home.tsx`.
🎯 Why: To avoid redundant O(N) array allocations and improve React rendering performance when computing metrics that iterate over the same data sequentially.
📊 Impact: Halves the O(N) iteration overhead during render cycles across the primary data array (`weeksData`) when generating annual summary points and metrics. Prevents redundant object allocations.
🔬 Measurement: Verify by loading the primary dashboard and observing identical metric values, but with fewer execution cycles during re-renders. Checked functionality and passed unit tests via `pnpm check && pnpm test`.
