## 2024-05-17 - Unintended Callbacks recreation with generic mutation objects
**Learning:** When using React Query or tRPC mutation objects as dependencies in `useCallback` or `useEffect` hooks, depending on the entire mutation object (e.g., `[fetchFromApi]`) causes the hook to recreate on every mutation state change (like `isLoading` changing from true to false). This negates the benefits of memoizing child components with `React.memo` since their prop references will keep changing.
**Action:** Always use the stable mutate function specifically (e.g., `[fetchFromApi.mutate]`) in dependency arrays for event handlers that fire mutations to maintain referential stability.
